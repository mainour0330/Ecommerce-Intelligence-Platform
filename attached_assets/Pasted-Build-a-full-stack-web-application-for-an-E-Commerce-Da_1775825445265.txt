Build a full-stack web application for an "E-Commerce Data Intelligence Platform".

The application should include both frontend and backend components.

🔹 General Requirements:
- Use Python for the backend (FastAPI preferred)
- Use a clean and modern frontend (React or simple HTML/CSS/JS if needed)
- The UI should look professional, modern, and dashboard-like
- Use dummy/mock data for now (no real database required yet)

---

🔹 Frontend صفحات التطبيق:

1. Dashboard Page:
- Show KPIs:
  - Total Sales
  - Number of Orders
  - Average Order Value
- Include charts:
  - Sales over time (line chart)
  - Top products (bar chart)
- Clean layout with cards and charts

2. Customer Analytics Page:
- Show customer segmentation
- Display sample customer insights
- Table of customers with metrics

3. Predictions Page:
- Section for "Customer Churn Prediction":
  - Input fields:
    - number of orders
    - total spending
    - last purchase date
  - Button: Predict
  - Show result (e.g., "High risk" or "Low risk")

- Section for "Demand Forecasting":
  - Dropdown to select product
  - Display predicted sales (mock chart)

4. Real-Time Monitoring Page:
- Show live orders (simulate with updating list)
- Display latest events (new order, payment, etc.)

---

🔹 Backend (FastAPI):

Create the following endpoints with mock responses:

- GET /kpis
  → returns total sales, orders count, avg order value

- GET /sales-trend
  → returns time series data

- POST /predict-churn
  → takes user input and returns prediction result

- GET /forecast
  → returns mock forecast data

- GET /live-orders
  → returns simulated recent orders
