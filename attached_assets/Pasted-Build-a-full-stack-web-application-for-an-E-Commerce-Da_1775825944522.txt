Build a full-stack web application for an "E-Commerce Data Intelligence Platform" with a highly professional, modern, and visually engaging UI.

The application should include both frontend and backend components.

---

🔹 Tech Requirements:
- Backend: Python (FastAPI)
- Frontend: React (preferred) or modern HTML/CSS/JS
- Use clean architecture (separate frontend and backend)
- Use mock data for now (no real database yet)

---

🔹 UI/UX Design Requirements (IMPORTANT):

- Use a modern dashboard style inspired by SaaS products
- Use a vibrant and attractive color palette:
  - Primary: Deep Blue or Indigo
  - Secondary: Purple or Cyan
  - Accent: Bright Orange or Neon Green for highlights
- Use gradients where appropriate (e.g., buttons, headers)
- Cards with soft shadows and rounded corners
- Smooth hover effects and transitions
- Clean typography (modern fonts)
- Sidebar navigation with icons
- Dark mode preferred (optional toggle for light mode)

Make the UI feel like a real startup analytics platform (similar to Stripe, Notion, or modern BI tools).

---

🔹 Frontend Pages:

1. Dashboard Page:
- KPI cards:
  - Total Sales
  - Total Orders
  - Average Order Value
  - Customer Count
- Charts:
  - Sales over time (line chart)
  - Revenue by category (bar chart)
  - Orders distribution (pie chart)
- Animated counters

---

2. Customer Insights Page:
- Customer segmentation (High / Medium / Low value)
- Table with filters and search
- Highlight top customers
- Add visual badges

---

3. Predictions Page:

A. Customer Churn Prediction:
- Input fields:
  - number of orders
  - total spending
  - recency (days since last purchase)
- Predict button
- Show result with styled alert:
  - High Risk (red)
  - Low Risk (green)

B. Demand Forecasting:
- Product dropdown
- Display forecast chart
- Show predicted sales trend

---

4. NLP Insights Page (VERY IMPORTANT):

Add a Natural Language Processing section for customer reviews:

- Sentiment Analysis:
  - Show % Positive / Negative / Neutral
  - Use colored indicators

- Word Cloud:
  - Display most common words in reviews

- Top Complaints:
  - Extract and display most frequent issues (mock)

- Review Explorer:
  - List of reviews with sentiment label

---

5. Real-Time Monitoring Page:

- Simulated live feed:
  - New orders
  - Payments
  - Reviews
- Auto-refresh every few seconds
- Highlight new events visually

---

🔹 Backend (FastAPI):

Create endpoints with mock data:

- GET /kpis
- GET /sales-trend
- POST /predict-churn
- GET /forecast
- GET /nlp-insights
- GET /live-events

Each endpoint should return realistic structured JSON.

- Loading spinners while fetching data
- Error handling UI
- Responsive design (desktop + tablet)

  - /frontend

This is a prototype for a production-level data platform that will later integrate:
